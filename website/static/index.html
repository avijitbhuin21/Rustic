01 — The editor

Everything you expect from an editor. Then some.

A real IDE surface — not a chat window with a file picker bolted on.

A built-in agent with real tools

Read, edit, create and move files. Run commands in background PTYs it can poll. Fetch and search the web. Generate images and video. Every tool runs behind a Chat / Edit / Auto permission model — you decide how much rope it gets.

Per-message checkpoints

Every turn snapshots the whole project into a gix shadow repo. One click reverts files and the chat to any earlier point.

Integrated terminals

ConPTY / portable-pty backed, grid and split layouts, scrollback that survives remounts. The agent sees the same terminals you do.

Monaco, multi-tab, LSP

The same editor core as VS Code, with tree-sitter highlighting and previews for Markdown, images, PDF, docx, xlsx and notebooks.

A browser the agent can drive

Embedded Chromium with DevTools access: click, type, fill forms, read the console, inspect network requests, take screenshots, run Lighthouse. It verifies its own UI work instead of guessing.

Skills, workflows, @ & /

Reusable instruction bundles and saved playbooks, installable from GitHub. Mention files and live terminals with @; invoke skills inline with /.

Keys never touch the webview

API keys live in the OS keychain. The frontend only ever sees a sentinel; the Rust backend resolves the real secret.

Multi-project workspace

Open several repos at once. Global search, git status, diffs and history — all pure Rust via gix, no C toolchain required.

02 — Orchestration

One agent is good. A team is better.

Rustic treats agents as first-class citizens — its own, and everyone else's.

  1. 01

    Sub-agents that offload context

    Delegate read-only exploration, research, or a self-contained chunk. Children return a summary; the host keeps the full picture. Concurrent writes go through a 3-way merge guard so parallel edits never clobber each other.

  2. 02

    Peer agents in the same project

    Run several top-level tasks at once. Agents can see who else is live, what files they've written, and message each other to claim or yield an area.

  3. 03

    Bring your existing CLI agents

    Claude Code, Codex and Antigravity run as chats inside Rustic with hidden PTYs — same panel, same project, same terminals.

    Claude Code Codex Antigravity
  4. 04

    Memory that survives the session

    A fragmented project memory the agent reads at task start and writes back at the end — conventions, gotchas, decisions — so it stops repeating itself.

03 — rustic-server

Same agent. Any browser.

The desktop app and the headless server share one Rust core. Deploy rustic-server to a box you own and open Rustic from a phone, a tablet, or a locked-down work laptop.

  • Single container: Rust binary + web frontend + node/uvx for MCP
  • Embedded Chromium for the agent browser
  • Cloudflare quick-tunnel previews for dev servers
  • Cloud sync: push your whole environment up, pull it down anywhere
  • Go, Rust, Bun and TypeScript toolchains baked in
